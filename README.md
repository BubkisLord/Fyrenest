# Fyrenest
NOTE: this mod is no longer maintained so issues will likely remain unresolved for the forseeable future.
Some features of the mod are buggy and non-functional, and may mess with your save file data surrounding charms.
**Use this mod at your own risk.**

It is regrettable that the mod has been left in this way, as in the years ago I worked on this I was new to programming and poured a lot of effort into this project. Ultimately I think I got overexcited and did too much too fast, leading to a messy and buggy final result. I apologise for those who wanted to enjoy more out of this mod and faced softlocks, bugs, or errors.

## Overview
This mod is compatible with Transcendance and Benchwarp.
Currently, you cannot pick up charms via randomizer,
but you can gain them when you get the requirements through the randomizer.
For example, this means that if you get shadow dash from a randomized pickup,
you will gain powerful dash.
